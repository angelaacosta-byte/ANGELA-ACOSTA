## Thesis project
**Sustainable Import Patterns of Tissue Parent Rolls in Peru (2020–2025): A Machine Learning Analysis of Customs Import Records**

**Problem:** customs import records have no environmental field, so it is unknown how much of the tissue fibre that Peru imports for local conversion is recycled or certified. This project measures it from 2,994 real import declarations (Veritrade / SUNAT, 2020–2025).
